# وضع الكتابة

يدعم وضع الكتابة إنشاء الكيانات وتحريرها وحذفها مباشرة — عمل رسم حقيقي على الويب. تبدأ كل جلسة برسم جديد فارغ.

### الشريط العلوي (Ribbon)

يعرض Ribbon جميع علامات AutoCAD-style بالكامل:

| العلامة | الأوامر |
|---|---|
| File | فتح |
| Draw | خط، دائرة، قوس، مستطيل، خط متعدد، Hatch، نص، MText، إلخ. |
| Modify | نقل، نسخ، إزاحة، قص، تمديد، تدوير، تحجيم، عكس، Array، إلخ. |
| Properties | لون، نوع الخط، سُمك الخط |
| Measure | جميع أوامر القياس |

### Command Line

نافذة Command Line في أسفل اللوحة تسمح بكتابة أسماء الأوامر مباشرة (مثل `L` + Enter لرسم خط، `C` + Enter لرسم دائرة). يدعم:
- عرض مطالبات الأوامر والمحفوظات
- إدخال القيم الرقمية والإحداثيات
- استخدام أسهم لأعلى/أسفل للتنقل في محفوظات الأوامر

### شريط الأدوات على الجانب الأيمن

يتضمن شريط الأدوات أيضًا **مجموعة أدوات التحديد / التحرير**:

- تحديد
- تحريك
- تكبير إلى الحدود
- تكبير النافذة
- مجموعة أدوات القياس
- وضع القراءة
- تبديل الخلفية الفاتحة/الداكنة

### اللوحات المثبتة

| اللوحة | الوصف |
|---|---|
| Properties | خصائص الكائن المحدد (النوع، الإحداثيات، اللون، نوع الخط، سُمك الخط، إلخ.)، قابلة للتحرير |
| Measurements | إدارة نتائج القياس |
| Statistics | إحصائيات استخدام الكتل |
| Missing Resources | تنبيهات الخطوط / المراجع الخارجية |

## الجهاز اللوحي (Pad)

يقع تخطيط الجهاز اللوحي بين سطح المكتب والجوال، لكن وضع الكتابة يحتفظ بالمكونات الكاملة المطلوبة للتحرير:

- يحتفظ Ribbon بالعلامات الكاملة، لكن أزرار الأوامر تنهار إلى أيقونات
- يُحتفظ بشريط الأدوات على الجانب الأيمن
- يُنهار Command Line إلى شريط صغير افتراضيًا؛ انقر للتوسيع
- يمكن توسيع اللوحات المثبتة كأدراج جانبية
- يعرض شريط الحالة الأزرار الأساسية بشكل مبسط

## الجوال

في وضع الكتابة على الجوال، يتم تنفيذ Command Line وقدرات الرسم/التحرير الكاملة عبر **تراكب أوامر الجوال**، يحل محل شريط العلامات السفلي.

### تراكب الأوامر

عند تنفيذ أمر رسم أو تحرير، يظهر شريط عمليات الأوامر في أسفل الشاشة، يحتوي على:
- مطالبة الأمر الحالية
- أزرار ✓ تأكيد / ✗ إلغاء
- لوحة منبثقة للإدخال الديناميكي (DYN)

### طرق الإدخال

يستخدم الرسم على الجوال طرق الإدخال التالية:
- **إدخال النقطة بالنقر**: انقر على الشاشة (<0.5ث) لإنشاء نقطة
- **إدخال النقطة بالسحب**: اضغط مطولًا على الشاشة (>0.5ث)، أدخل وضع التحديد بالسحب وأفلت
- **الفأرة المحاكية**: ممكّنة افتراضيًا؛ الضغط المطول يُظهر خط تصويب فوق الإصبع؛ موضع الإدخال الفعلي يعتمد على خط التصويب
- **المكبر**: تبديل في الإعدادات؛ مكبر دائري HUD يكبّر منطقة الإصبع

### العودة التلقائية

أثناء تنفيذ الأمر، يُخفى شريط الحالة مؤقتًا (يتولى تراكب الأوامر الإدخال). بعد انتهاء الأمر، يُستعاد شريط الحالة.
