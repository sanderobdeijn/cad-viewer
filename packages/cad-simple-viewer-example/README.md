# CAD Simple Viewer Example

A vanilla TypeScript demo that embeds [`@mlightcad/cad-simple-viewer`](../cad-simple-viewer/README.md) with the simple UI plugin. The app opens straight into a new blank drawing, and **New** creates another one.

## Run it

```bash
pnpm install
pnpm dev:simple
```

Pass `?progressive=1` in the URL to turn on progressive rendering.
